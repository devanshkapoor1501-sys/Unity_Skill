# Reviewed capability data

versioned expanded recipes are in examples/simple_arena/recipes and bundled
polyforge/data/arena_recipes.json. Request examples are in examples/static_recipes.

The executable catalog is bundled in the Python package; only validated,
available operations may enter it. A sample descriptor is not an implementation.
