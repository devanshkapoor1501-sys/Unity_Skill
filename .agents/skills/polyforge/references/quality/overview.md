## quality.recovery

Diagnose structured failures using exact registered evidence. Native binding repair is bounded and transactional. Unknown causes return a specialist proposal or BLOCKED; native reimport and original profile invariants prove rollback. Never count restored bytes or stale PASS labels as recovery success.

Support: REFERENCE_ONLY; knowledge: REFERENCE_ONLY until version/workflow evidence.
Pinned applicability: {"unity": ["6000.6.3f1"]}.

Decision: Scoped registered repair for exact native symptoms; original-specialist review for unfamiliar code.

Contrasts: Restore a measured prefab scale fault. Unknown compiler/API failure requires a fresh isolated probe.

## quality.evaluation

Technical checks, subjective review and original-brief gameplay acceptance are separate vetoes. Public same-host tests are not a protected evaluator. Six mutants establish bounded development checks; complete game acceptance and hardware performance need separate actual evidence.

Support: REFERENCE_ONLY; knowledge: REFERENCE_ONLY until version/workflow evidence.
Pinned applicability: {"unity": ["6000.6.3f1"]}.

Decision: Deterministic tests for invariants; human review for aesthetics; separately controlled evaluator for hidden acceptance.

Contrasts: Wrong damage must fail despite a supervisor approval. No rendered FPS result means performance NOT_RUN.

## Role playbook

Inspectors/supervisor: read sealed bytes, independent oracles and actual visuals when supplied; candidate writes are forbidden. Produce separate technical, subjective and gameplay findings with exact test identities. Missing vision means artistic REVIEW; missing external evaluator means PARTIAL. Native recovery requires bytes plus native references and scenarios, with quarantine on failed proof.
