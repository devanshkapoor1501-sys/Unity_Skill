# Expanded public release-development suite

This suite preserves the twelve `development-v1` tasks and their exact brief
bytes. It adds two public complete 3D game specifications, bringing the visible
sample to one complete 2D and two complete 3D game tasks. All fourteen entries
remain `DEV_FIXTURE`; none is an independently owned unseen combination.

Run it using an explicit suite path:

```console
polyforge benchmark run --suite benchmarks/release-development-v1/suite.json --arm D --output results/release-D --json
```

The declared five repetitions plan seventy cases per arm. Missing model adapters,
frozen execution metadata, finite token budgets and independently frozen scorers
produce BLOCKED rows, not invented trials. The garden puzzle deliberately asks
for mechanics outside the currently registered arena/platformer contracts.
Those gaps must remain visible rather than selecting an available game silently.

The release requirement for a genuinely withheld full-game variant, at least
three independently controlled unseen mechanic/genre combinations, actual arm
comparisons and external leak qualification remains unmet. This extension does
not substitute public tasks for those gates.
