# Independent evaluation boundary

Public development fixtures are editable and visible to generators. They are
never held-out qualification. Independent evaluators freeze the original brief,
task identity, scoring version, rubric hashes, and budgets outside this repo.
No hidden briefs, answers, traces, or private scoring fixtures belong here.

Phase 0 provides schemas and interfaces, not executable baseline evaluation.
The unavailable grader returns BLOCKED and game PARTIAL. External result
verification, leak probes, and actual four-arm execution arrive in later phases.

Only COMPLETE_GAME_2D/3D attempts enter accepted-game rate. Asset, animation,
mechanic, and repair tasks have separate denominators. C/D must have identical
general Blender/Unity MCP tools, versions, permissions, and budgets. Preserve
failures/timeouts and separate cold installation from warm execution costs.

Planned suite: twelve public development categories plus at least three
evaluator-owned full-game tasks, five runs per arm/task where budget permits.
Small samples are exploratory. External evaluator access or a budget being
unavailable must remain visible; do not invent results.
