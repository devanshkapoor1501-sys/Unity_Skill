Existing protocol.py unchanged; EvaluationRequest, BaselineRunner and AcceptanceEvaluator signatures retained.
load_suite verifies bounded finite JSON, public task IDs/types/budgets and original brief SHA256. Snapshot freezes input file bytes, task metadata and arm execution metadata. Every execution rechecks snapshot before mutation.
run_suite permits only injected Python protocol implementations, never user source paths, dynamic plugins, subprocess descriptions or arbitrary commands. Absent host/model adapters remain BLOCKED with executed=false, evaluation NOT_RUN, cost unknown. Public fixture placeholders and null token budgets cannot become qualified trials.
Injected adapters are trusted integrations. They receive public input/budget context in artifact_root and own process deadline/cancellation enforcement. The harness measures elapsed wall time and validates reported usage; returning after a wall/tool/token overrun is FAIL, timeouts censored. A synchronous protocol cannot safely terminate arbitrary Python or prove undisclosed provider usage. No fake termination claim.
Each task/seed retains original identity, configuration hash, real execution/evaluation status, errors, timeout/censoring, intervention count and known or unknown cost. Existing ledgers must never be overwritten. All four arms use identical runner interface; no arm routes automatically through the full engine.
C/D comparison requires exact generic tool versions, inventory, permissions, model/thinking/hardware/OS/licensing/assets/budgets and manual intervention policy parity. Missing or mismatched evidence is NON_ATTRIBUTABLE. Same arm/config changes never pool.
Task-stratified success includes six classes; accepted-game denominator only actual attempted eligible complete games including failures/blocked/timeouts. Planned unexecuted rows do not become attempts; with no executed eligible complete game the primary rate is NOT_MEASURABLE. Every rate supplies exact numerator/denominator and stdlib Wilson 95% interval. Time medians cover all attempts separately from accepted-only; censored and unknown-cost counts remain visible. Genre/platform/complexity strata remain separate.
Reports are offline finite JSON, human text and HTML returned as data; all untrusted HTML text escaped. CLI owner writes explicitly requested output. Missing independently governed holdouts remain BLOCKED; public tests cannot qualify held-out generalization or substantiate statistical superiority.
No production files changed until parent confirms unchanged baseline complete. No full suite/native/network/dependency/commit operations delegated to this agent.
