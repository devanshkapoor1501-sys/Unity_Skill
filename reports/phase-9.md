## Twelve-defect pack and limits

Detection and automatic repair are separate qualifications. The typed twelve-case
diagnostic pack is an offline contract test, not twelve invented native repairs.

| Defect | Additional executed evidence / automatic route |
| --- | --- |
| Stale GUID/reference | Native missing-GUID/reference tests and measured reconstruction; registered native wiring rebuild. |
| Wrong FBX axes/scale | Real importer/prefab fault, native diagnosis, transactional repair and verified restore. Source-side export metrics remain independently checked. |
| Degenerate geometry | Real Blender saved-source fault/audit regression; typed specialist handoff. Automatic generic source regeneration is BLOCKED without reconstructable inputs. |
| Unity API mismatch | Typed compiler/context fixtures distinguish API, runtime/Editor assembly, package and reload failures. No arbitrary patch or package install; BLOCKED. |
| Missing component | Real native component/source-reference faults and required Editor tests; supported managed binding reconstruction. |
| Wrong sprite curve | Real native missing/reordered PPtr-curve tests, exact imported IDs and playback checks; unsupported forensic source reconstruction stays BLOCKED. |
| Broken action slot | Typed slotted-action diagnosis and registered motion contracts; real native rig/skin/transition regressions run separately. Automatic arbitrary motion reconstruction stays BLOCKED. |
| Owned timeout/crash | Actual owned-process kill, native timeout, quarantine and successful native resume; unsafe worker replay BLOCKED. |
| Swapped/missing material | Actual native material/value/reference negative tests and cross-tool restore. |
| Misleading clip | Typed misleading-clip fixture plus measured native skin/transition checks; clip labels alone confer no approval. Unsupported automatic reconstruction BLOCKED. |
| Missing required mechanic | Original-brief veto, omitted-damage fixture and real win/damage/navigation/input mutants. |
| Misleading PASS | Empty/skipped/wrong XML and unexecuted/malformed telemetry denied by exact identity/scoring checks; no repair success inferred. |

General original-input reconstruction for geometry/export, standalone 2D,
arbitrary sprite/motion jobs, novel APIs and workers is not advertised. The
supported recovery profile is a managed static project with its applicable
combined arena/animation/sprite registrations. Unsupported projects/run types
fail explicitly. This phase does not qualify protected evaluator ownership,
OS isolation, native host delegation, aesthetic acceptance, new standalone
builds or performance. Those statuses remain separate from operation PASS.
