## Constraints and decisions

- Keep the user-selected checkout; branch codex/polyforge-phase-7, base ee490d6. No Phase 8 work or automatic remote publication.
- User's explicit phase-start instruction authorizes the reviewed blueprint implementation; avoid redundant plan-approval interviews.
- Task classification accepts explicit task_class/domain_tags and preserves exact brief; ambiguous natural-language interpretation stays host-assisted REVIEW.
- Sequential role mode is the initial native implementation. Host subagent execution remains unavailable unless a tested host adapter establishes permission/identity isolation; never equate role identity with protected evaluator ownership.
- No reference text grants execution permission. Unknown tools/capabilities fail closed. Network and arbitrary generated-code execution remain disabled.
- Leases require owner token, process birth identity and TTL; reclaim only expired/dead owners. Candidate revisions and approval digests are immutable; resume reuses committed results and rejects conflicting writes.
- Preserve Phase 6 tests/project source; animation integration adds a separate fixture scene/prefab. Only native Editor APIs mutate Unity assets.
- Every capability keeps model-free JSON input/output and pure invalid/dry-run behavior. >=90% security/contract coverage; release-only external gates remain explicit.

- Crash between output write and result publication cannot double-integrate or bless partial output.
- Expired lease never lets a second process overwrite an active writer; cancellation must fence commits.
- Reviewer cannot alter candidate, self-approve or stamp borrowed hidden-evaluator identity.
